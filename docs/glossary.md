# Glossary

| Term | Meaning |
| --- | --- |
| BOL / EOL | Beginning of life / end of life (EOL is an application-defined SOH threshold, commonly 80 %) |
| C-rate | Current relative to the current that discharges the nominal capacity in one hour (1C) |
| CC-CV | Constant-current then constant-voltage charging |
| CL / ORI | Conductivity loss / ohmic resistance increase, a degradation mode |
| Coulombic efficiency | Discharge capacity divided by the preceding charge capacity |
| CRPS | Continuous ranked probability score, a proper scoring rule for probabilistic forecasts |
| DFN / P2D | Doyle-Fuller-Newman pseudo-two-dimensional electrochemical model |
| DoD | Depth of discharge, the fraction of capacity removed in a cycle |
| DRT | Distribution of relaxation times, derived from an impedance spectrum |
| DTV | Differential thermal voltammetry, dT/dV against voltage |
| DVA | Differential voltage analysis, dV/dQ against capacity |
| ECM | Equivalent-circuit model (for example Thevenin with RC pairs) |
| EIS | Electrochemical impedance spectroscopy |
| EKF / UKF / PF | Extended Kalman filter / unscented Kalman filter / particle filter |
| Few-shot, k-shot | Adapting a model with only k examples (here, k target cells) |
| HPPC | Hybrid pulse power characterisation, a pulse test giving resistance at set SOCs |
| ICA | Incremental capacity analysis, dQ/dV against voltage |
| Knee | The point where capacity fade accelerates abruptly |
| LAM_PE / LAM_NE | Loss of active material at the positive / negative electrode |
| LLI | Loss of lithium inventory |
| MAE / RMSE / MAPE | Mean absolute error / root-mean-square error / mean absolute percentage error |
| OCV, pseudo-OCV | Open-circuit voltage; a low-rate (for example C/25) charge or discharge used as its proxy |
| PICP | Prediction-interval coverage probability |
| PINN | Physics-informed neural network |
| RPT | Reference performance test, the periodic standard test that produces SOH labels |
| RUL | Remaining useful life, cycles or time until EOL |
| SEI | Solid electrolyte interphase |
| SOC / SOH / SOF | State of charge / state of health / state of function |
| SPM / SPMe | Single-particle model / single-particle model with electrolyte dynamics |
| TCN | Temporal convolutional network |
| UQ | Uncertainty quantification |
