Sell a battery

You need a valuation reference first. Scan the pack’s passport on the main page and it gives you one — that reference is what a buyer opens to see the health, the wear and the workings.

Prices are estimates from each battery’s own passport data and published material markets, not offers. Traction packs are UN3480 Class 9 dangerous goods — moving one is a job for a carrier who is set up for it.
